# 尼古喵喵的吵鬧公寓

上方的 **2D／3D** 按鈕可切換兩種網頁風格：原有手繪 SVG 公寓，以及用真正立體模型組成的 3D 公寓。首次開啟預設為 2D，之後會記住風格選擇。切換時保留喵喵、目前的朋友、日夜與靜音設定，並清理尚未播完的互動。

滿版互動小公寓。尼古喵喵一直留在家裡，左側頭像選單可以邀請一位朋友作客；最上方的圖示讓朋友離開。場景最多是喵喵加一位朋友，喵喵的位置和元件實例始終保留。點朋友會對喵喵惡作劇，點喵喵抽煙則會引起朋友的不同反應，沒有好感度、整潔值、任務或評分。

兩人與背景共用場景座標，站姿鞋底對齊地面陰影，喵喵的坐姿貼合坐墊。朋友到場會與喵喵打招呼；更換或送走朋友會清除上一段煙霧、道具、音效與延遲反應，同時保留喵喵、日夜及靜音設定。

2D 角色為手寫 SVG 的粉絲重繪；3D 角色以共用的連續曲面網格建立臉型、衣服、四肢與尖髮束，沿用同一份髮色、服裝與角色設定。皮膚五官使用 UV 貼圖，頭髮、布料、丹寧、皮革及家具帶有原創色彩、粗糙度與凹凸貼圖。貼圖由程式在本機繪製，不使用官方圖片或模型，也不載入外部圖片、字型與音檔。3D 繪圖使用隨專案附帶的 Three.js r180（MIT 授權）；執行時不依賴 CDN，也不需要 npm 或建置程序。

## 啟動

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

開啟 <http://127.0.0.1:4173>。請經 HTTP 載入，不要直接以 `file://` 開啟 ES Modules。

## 3D 操作

- 點上方 **3D** 切換立體公寓；**2D** 隨時返回原版。
- 拖曳空間可旋轉視角，滾輪或觸控雙指縮放；下方環繞圖示重設視角。
- 直接點立體角色和房間道具互動；下方圖示也提供角色、收音機、風扇及日夜操作，支援鍵盤。
- 3D 需要瀏覽器支援 WebGL 2；無法建立畫面時會保留可操作的 2D 公寓。

3D 程式與模型只在首次切換時載入。回到 2D 會停止 3D 繪製；朋友離開時回收其網格、材質和貼圖，離開頁面時釋放繪圖資源。五官貼圖包覆有下顎、臉頰及鼻形的立體頭部；眨眼與表情會更新貼圖，動作仍由立體網格呈現。

五位角色共用頭身比例設定，分別控制頭部、軀幹與手臂尺寸。喵喵的坐姿由骨盆與兩條彎曲交叉的褲管組成，保留膝蓋和小腿的厚度；手掌、手指、耳朵與後腦髮束都有立體曲面。五官、頭髮、香菸和煙霧錨點會隨頭部比例一起調整。

## 直接點畫面

| 角色／物件 | 反應 |
| --- | --- |
| 尼古喵喵 | 點煙、吐煙圈，偶爾吐出魚形煙圈；朋友聞到煙味會丟拖鞋、打噴嚏、搧煙或拋罐子。第三口還會嗆到自己。 |
| 妹妹喵 | 朝喵喵丟拖鞋，命中後笑個不停，喵喵頭冒星星。 |
| 藥喵 | 大噴嚏吹亂喵喵的瀏海，喵喵也跟著打噴嚏。 |
| 關西喵 | 把煙搧回喵喵，再用紙扇輕敲喵喵的頭，兩人一起笑。 |
| 酒喵 | 把罐子拋給喵喵，兩人輪流打嗝、笑成一團。 |
| 電風扇 | 吹走煙霧、吹動窗簾，也會吹亂喵喵和朋友的頭髮。 |
| 收音機 | 播放跑調的音樂，讓喵喵和朋友一起亂舞。 |
| 吊燈 | 切換日夜。 |

第一次互動後自動啟用原創合成音效，右上角喇叭圖示可靜音。旁邊的箭頭重置場景，保留喵喵、目前來訪的朋友與靜音偏好。每段雙人互動有短暫播放時間，避免連點打斷笑點；選單隨時可以更換或送走朋友。

支援 Tab、Enter 和空白鍵操作選單及按鈕。在頁面空白處按 Space 讓喵喵抽煙、M 切換靜音、R 重置。選單有可存取的名稱與邀請狀態，並保留螢幕閱讀器事件描述；遵循系統的「減少動態效果」設定。

## 可重用模組

| 檔案 | 職責 |
| --- | --- |
| `js/characters.js` | 共用頭、耳、眼睛、嘴、手臂、服裝和腿部繪圖函式；五位角色由外觀設定組成。 |
| `js/characters.css` | 共用表情與香菸顯示狀態。 |
| `js/components.js` | `<character-picker>` 邀請選單、`<neko-actor>` 角色、`<room-prop>` 物件；共用頭像與角色繪圖。 |
| `js/data.js` | 角色反應與道具位置設定。 |
| `js/layout.js` | 固定喵喵座位與朋友站位，依實際輪廓安排雙人間距、腳底座標與側欄留白。 |
| `js/interactions.js` | 可復用的雙人反應、飛行道具、命中效果與依朋友設定的煙霧反應。 |
| `js/scene.js` | 原創 SVG 公寓、物件登錄表與重複實例。 |
| `js/effects.js` | 可回收的煙霧粒子。 |
| `js/gags.js` | 拖鞋、紙扇、罐子、星星、煙圈、風等共用視覺效果。 |
| `js/sound.js` | Web Audio 原創合成音效，包含打火、吐煙、咳嗽、打嗝、彈簧、敲擊、喵聲和走音銅管。 |
| `js/app.js` | 固定主人與單一訪客的生命週期、到訪招呼與互動協調；邀請、送客、重置時清理延遲、粒子和音效。 |
| `js/three/characters3d.js` | 復用外觀設定建立立體角色、表情、姿勢與互動錨點。 |
| `js/three/geometry3d.js` | 帶 UV 的頭部曲面、衣服輪廓、連續肢體與尖髮束網格。 |
| `js/three/textures3d.js` | 共用原創材質貼圖工廠：五官、髮絲、布紋、木紋、粗糙度與凹凸細節，以及資源回收。 |
| `js/three/view3d.js` | 3D 房間、鏡頭、燈光、立體點擊判定與模型生命週期；將錨點投影給共用特效。 |
| `js/three/style.css` | 風格切換、3D 畫面與鍵盤操作圖示。 |
| `assets/vendor/three/` | 固定版本的 Three.js r180 與原始 MIT 授權。 |
| `styles.css` | 滿版場景、角色動作、日夜與響應式構圖。 |

`renderCharacter(idOrConfig, { pose, instanceId, portrait })` 可獨立生成完整角色或選單頭像 SVG。以同一組繪圖函式更換外觀設定，不需要複製整份角色標記；站姿、坐姿與表情分開控制。

## 瀏覽器驗證

使用 Python 標準函式庫連接測試用 Chrome DevTools Protocol，無額外依賴。Chrome 需以獨立設定檔搭配 `--headless=new --remote-debugging-port=9222` 啟動。

```sh
python3 tests/interaction_check.py
python3 tests/style_check.py
python3 tests/newtexture_check.py
python3 tests/browser_check.py --url http://127.0.0.1:4173 \
  --width 390 --height 844 --mobile --screenshot /tmp/neko2-mobile.png
```

`style_check.py` 使用具備 WebGL 2 的測試 Chrome（預設偵錯連接埠 9223），驗證風格切換、立體模型、鏡頭、互動與相容性降級。原有 2D 互動檢查仍使用 9222。

`newtexture_check.py` 檢查五位角色的 UV、材質貼圖通道、臉型、表情／眨眼貼圖切換，以及重複邀請朋友時的 GPU 貼圖回收。
